# RhythmRoot Demo Video Script

This script is designed for a clear, polished 2-minute presentation of the project.

## Suggested video length
- Total: about 2 minutes
- Style: calm, confident, and easy to follow

## Script

### 0:00-0:20 — Introduction
"Hi, I’m presenting RhythmRoot, a practical habit-planning web app designed to help people build consistency and stay organized in everyday life. The goal is to make small routines visible, measurable, and easier to maintain."

### 0:20-0:45 — What the app does
"Users can create habits, choose a category and frequency, and mark them complete for a selected day. The app then calculates streaks and weekly progress so users can see how consistently they are following their routine."

### 0:45-1:10 — Main interaction demo
"Here I’m adding a habit, setting its reminder, and marking it complete for today. You can also search, filter, and sort habits to quickly find the ones you want to review."

### 1:10-1:35 — Extra value feature
"A helpful extra feature is the public holiday planner. The app uses the Nager.Date API to show upcoming holidays for a chosen country, which helps users plan around important dates and avoid breaking their routine."

### 1:35-1:55 — Deployment and purpose
"This project was built as a static web app and can be deployed on multiple web servers. The same app can be served through a load balancer, making it more reliable and easier to scale."

### 1:55-2:00 — Closing
"Overall, RhythmRoot is a useful tool that combines habit tracking with real-world planning, and it demonstrates how a simple web app can solve a meaningful everyday problem."

## Presentation tips
- Speak slowly and clearly.
- Show the app on screen while explaining the features.
- Highlight the habit tracker, streaks, and holiday planner.
- End with a confident summary of the app’s purpose.
